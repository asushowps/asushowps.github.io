CONTROLS & INSTRUCTIONS

Keyboard Controls

← / A : Left
→ / D : Right
↑ / W : Rotate
↓ / S : Soft Drop
Space : Hard Drop
C : Hold Piece
P : Pause / Resume Game
H : Instructions Key

How to Play

  • Fit falling blocks into complete horizontal lines.
  • Clear lines to gain points and level up speed.
  • Swap key blocks into the Hold slot for strategic moves.
  • Mobile touch buttons work directly on smartphones.
